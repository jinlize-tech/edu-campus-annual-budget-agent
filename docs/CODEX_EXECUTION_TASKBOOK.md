# JLZ-EDU-AG-026 Codex执行任务书

## 1. 基线

- 任务编号：`JLZ-EDU-EXPANSION-30-FULL-DELIVERY`
- 候选来源：`CAND-031`
- 正式产品：`JLZ-EDU-AG-026` / 校区年度预算编制
- 类型：Agent
- 批次：1
- 业务中心：12 经营决策与财务规划中心
- 版本基线：`EDUCATION_BASELINE_V1.0.0`
- 产品版本：`1.0.0`
- 许可证：Apache-2.0

## 2. 用户、痛点与目标

- 用户：校长、财务负责人、多校区经营管理者
- 痛点：年度预算通常由财务发模板给各部门，业务计划与预算脱节，后续难追踪假设和版本。
- 目标：从招生、课程、师资、校区产能和费用计划出发，组织多部门预算并生成版本化假设、汇总和审批。

## 3. 输入契约

| 键 | 名称 | 类型 | 必填 |
|---|---|---|---|
| `annual_targets` | 年度经营目标 | string | 是 |
| `enrollment_plan` | 招生节奏 | array | 是 |
| `course_plan` | 课程计划 | array | 是 |
| `pricing` | 价格与优惠 | array | 是 |
| `staffing_plan` | 人员与教师计划 | array | 是 |
| `compensation_rules` | 薪酬规则 | string | 是 |
| `fixed_costs` | 固定费用 | array | 是 |
| `capital_expenditure` | 资本支出 | array | 否 |
| `historical_actuals` | 历史实际 | array | 否 |
| `budget_months` | 预算期间 | integer | 是 |

## 4. 工作流

1. 明确预算边界
2. 收集业务驱动量
3. 建立联动模型
4. 分部门确认
5. 汇总与情景
6. 输出审批包
7. 设定月度跟踪

## 5. 阶段状态

| 阶段 | 动作 | 退出成果 |
|---|---|---|
| S1_SCOPE_CONFIRMATION | 确认目标、校区/岗位/课程范围、期限、交付格式和可用资料。 | 任务确认单与最多3个关键缺口 |
| S2_EVIDENCE_INVENTORY | 盘点年度经营目标、课程计划、招生节奏、班容、价格、教师编制、薪酬规则、固定费用、资本支出、历史实际，标记来源、版本、敏感字段与冲突。 | 证据清单、缺口表和冲突表 |
| S3_PROFESSIONAL_DIAGNOSIS | 围绕从招生、课程、师资、校区产能和费用计划出发，组织多部门预算并生成版本化假设、汇总和审批。进行专业诊断，形成问题树和优先级。 | 问题树、风险和优先级 |
| S4_SOLUTION_DESIGN | 按明确预算边界 → 收集业务驱动量 → 建立联动模型 → 分部门确认 → 汇总与情景 → 输出审批包 → 设定月度跟踪设计首选方案和受限备选方案。 | 方案、责任人、完成标准 |
| S5_HUMAN_CONFIRMATION | 由业务负责人复核输入事实、关键假设和最终成果适用范围。 | 确认记录、未决项和升级项 |
| S6_FINAL_DELIVERY | 生成完整交付成果，执行结构、证据、安全、品牌和独立安装检查。 | 最终成果、范围限制和复盘指标 |

## 6. 核心成果

- `年度预算`
- `驱动假设表`
- `月度分布`

## 7. 差异化与排重

- 与现有产品：现有校区筹建计划是项目计划，财务分析是事后分析；本产品是多阶段年度预算编制和版本协同。
- 排重检查：部分重叠；共享校区和财务数据，但输出年度联动预算和审批版本，不是综合经营 OS。
- 独立理由：只安装本 Agent 即可从业务驱动量生成独立预算方案。

## 8. 安全与人工门禁

- 复核角色：业务负责人
- 复核范围：输入事实、关键假设和最终成果适用范围
- 不调用外部收费API。
- 不自动修改外部系统、执行退款、审批合同、处分员工或联系外部人员。
- 高风险产品完成状态必须确认人工复核。
