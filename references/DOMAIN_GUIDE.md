# 校区年度预算编制领域指南

## 业务问题

年度预算通常由财务发模板给各部门，业务计划与预算脱节，后续难追踪假设和版本。

## 产品解决方案

从招生、课程、师资、校区产能和费用计划出发，组织多部门预算并生成版本化假设、汇总和审批。

## 输入质量要求

| 字段 | 名称 | 必填 | 质量要求 |
|---|---|---|---|
| `annual_targets` | 年度经营目标 | 是 | 招生、收入和成本约束 |
| `enrollment_plan` | 招生节奏 | 是 | 月度或季度目标 |
| `course_plan` | 课程计划 | 是 | 课程、班型、价格和课时 |
| `pricing` | 价格与优惠 | 是 | 课程价格和折扣口径 |
| `staffing_plan` | 人员与教师计划 | 是 | 编制、招聘和薪酬规则 |
| `compensation_rules` | 薪酬规则 | 是 | 固定、课时和提成口径 |
| `fixed_costs` | 固定费用 | 是 | 房租、行政、软件等 |
| `capital_expenditure` | 资本支出 | 否 | 设备、装修和一次性投入 |
| `historical_actuals` | 历史实际 | 否 | 用于校验假设 |
| `budget_months` | 预算期间 | 是 | 默认12 |

## 证据判断

- 用户原文优先于模型推断。
- 外部政策或公开事实应记录标题、发布机构、发布日期、URL、访问日期和适用范围。
- 无法核验时标记`EVIDENCE_UNVERIFIED`，不补造来源。
- 数据冲突必须并列展示，并说明对结论的影响。

## 人工复核

业务负责人应确认：输入事实、关键假设和最终成果适用范围。未经确认的内容只能作为草案。

## 主要风险

预算不是预测事实；必须基于真实假设并持续滚动；不替代财务核算和审批。
